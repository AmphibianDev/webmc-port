WebMC

A launcher for Minecraft in a browser. This page hosts no game files, no jars and no mods: your browser fetches every client from the official source at the moment you ask for it.

Click a version to play it, or press ↵ to start the top result. Only versions with a route can start; the rest explain what a port is and point at the nearest version that runs.

Nothing yet — the launcher starts empty. Type a version above.

Each version's route is decided by tools/plan.py: real Java in the browser (CheerpJ), a client this project compiled, a prebuilt port, or queued behind a named blocker. Fabric support and loader versions come from Fabric's own meta API (tools/fabric.py).
